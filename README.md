This is the GitHub page for Chia Wallet, the desktop wallet for the Chia blockchain. It runs on Windows, macOS and Linux and holds XCH, CAT tokens, offers, NFTs and DIDs in one self-custody account, in wallet mode or with a full node in farming mode. The keys stay on the device, encrypted by the operating system keychain, and the 24-word phrase is the backup that restores them. Everything published here points at the same tagged release: the installers, their SHA-256 values and the guides that explain what to do after the download.
